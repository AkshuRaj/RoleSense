## Query Testing Guide

### How to Use These Questions:
1. **Copy a question** from the relevant role category
2. **Query it in your RAG chatbot UI** using the question as input
3. **Verify** that the chatbot returns relevant information from the knowledge base
4. **Validate** that the response is accurate and complete
5. **Test coverage** by sampling questions from each category

### Expected Response Characteristics:
- Responses should cite specific numbers, dates, and metrics from the documents
- Answers should be role-contextual (engineering answers differ from finance answers)
- Responses should reference document sections when applicable
- Multi-part questions should address all components

### Success Criteria:
- ✓ Answer is factually accurate based on source documents
- ✓ Answer is relevant to the specific question
- ✓ Answer includes specific data points when available
- ✓ Answer maintains role/department context
- ✓ Response length is appropriate for the query complexity
